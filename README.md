# 旅ナビ（旅行用 Webアプリ）

iPhone の Safari で開いて「ホーム画面に追加」すると、アプリのように使える旅行アプリです。
サーバーは不要で、GitHub Pages にファイルを置くだけで動きます（データは各端末の中に保存）。

公開URL（GitHub Pages が main ブランチから配信されている場合）:
`https://inocozuchi.github.io/tabi-navi/`

## できること

| 画面 | 主な機能 |
|---|---|
| ホーム | 時刻（秒まで）と天気・1時間ごとの予報を常に表示／旅の進み具合／現在地から次の予定に間に合うか／次のアラーム／ピン留めメモ／各種道具 |
| 旅程 | スクショ（乗換案内・ホテル・飛行機・バスの予約画面）から旅程を一括作成／時系列・日ごと表示／「いま」の線と次の予定までのカウントダウン／乗り物ごとの色分け／予約済みチェック／乗り換え時間の警告／予備ルート（切替可）／スポット検索で自動入力／リマインド／カレンダー登録（.ics）／文字で共有 |
| アラーム | イヤホンからだけ鳴らす（マナーモードでも鳴る・イヤホンが外れたら鳴らさない）／連続アラーム（例: 6:00〜6:15に1分ごと15回を一括）／スヌーズ（間隔・回数）／繰り返し曜日／音をファイルから読み込み／だんだん大きく／音量／計算問題で停止／イヤホン節電モード・確実モード |
| 交通 | 乗換案内（Yahoo!乗換案内・Googleマップ・Appleマップ・NAVITIMEへ条件を渡して検索）／地図（現在地・旅程の場所・近くのコンビニ/トイレ/コインランドリー/銭湯など）／運行情報（いま遅れている路線・お気に入り路線・公式リンク） |
| 道具 | 行きたいリスト（スクショからスポットを蓄積→旅程に入れる・AIが旅程を提案）／旅のしおり（5種類のデザイン・印刷/PDF）／メモ（写真から文字化・予定に組み込み・リマインド）／旅費（旅程の料金を自動集計・支出記録・外貨→円・割り勘・予算）／持ち物リスト（ドミトリー用などのテンプレート）／通貨換算 |
| 旅仲間 | 共有コード（6けた）で参加・アカウント登録なし／ホストが参加受付をオン・オフ（オンの間だけコードが有効・重複なし）／旅程の同期・チャット・位置共有／脱退・追放・解散 |
| 設定 | ライト/ダーク/自動／天気の場所／Claude API キー／バックアップ・復元 |

## スクショの読み取り
- **Claude API キーあり**（設定で入力）: 画像を Claude（既定: `claude-opus-5-5`）に送り、構造化された予定として受け取ります。高精度。
- **キーなし**: 端末の中で文字を読み取り（Tesseract.js）、簡単な規則で予定に分けます。読み取り後に手で直せます。

## アラームのしくみ（制約）
Web アプリは iPhone の時計アプリのように「アプリを閉じていても鳴る」ことはできません。
そのため寝る前に「おやすみモード」を開始し、アプリを開いたまま置く必要があります。
- **イヤホン節電モード**（既定）: 画面を暗くつけたまま待機し、鳴らす時だけ音を出す。イヤホンの電池をほぼ使わない。
- **確実モード**: 無音を流し続けて待機。画面を消しても鳴り、イヤホンが外れた瞬間に検出して無音にする。

## 旅仲間の共有（Firebase）
`firebase-config.js` に自分の Firebase の設定を貼ってください（手順はファイル内とアプリの設定画面にあります）。
Firebase コンソールの Firestore ルールに、アプリの「設定 → 旅仲間の共有 → 共有サーバー」に表示されるルールを追加してください。

## ファイル
- `index.html` / `app.css` … 画面
- `js/` … 機能ごとのプログラム（`alarm.js` がアラームの心臓部）
- `sw.js` … オフライン対応
- `make-icons.mjs` … アイコン（PNG）を作り直す道具（`node make-icons.mjs`）
