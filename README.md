# 旅ナビ（旅行用 Webアプリ）

iPhone の Safari で開いて「ホーム画面に追加」すると、アプリのように使える旅行アプリです。
サーバーは不要で、GitHub Pages にファイルを置くだけで動きます（データは各端末の中に保存）。

公開URL（GitHub Pages が main ブランチから配信されている場合）:
`https://inocozuchi.github.io/tabi-navi/`

## 画面（下のタブ）

| タブ | 主な機能 |
|---|---|
| **旅程**（メイン） | いちばん上に時刻と天気（1時間ごとの予報）／いまの状況（次の予定までのカウントダウン・移動中の到着まで・現在地から間に合うか・遅延の発表・次のアラーム）／日ごとの時系列（行き先の天気つき）／色分け・予約済みチェック・乗り換え時間の警告・予備ルート／「遅れた…」で予定をまとめてずらす |
| **アラーム**（サブ） | イヤホンからだけ鳴らす／連続アラーム（例: 6:00〜6:14 に1分ごと15回）／スヌーズ・曜日・音ファイル・だんだん大きく・計算で停止／旅程の出発に合わせて自動提案 |
| 交通 | 乗換案内（各サービスへ条件を渡す）／地図・近くの施設／運行情報 |
| 道具 | 文字から取り込む／スクショから取り込む／行きたいリスト／旅のしおり／メモ／旅費／持ち物／通貨換算／旅仲間／おやすみモード |
| 設定 | ライト/ダーク／天気の場所／Claude API キー（料金の目安つき）／バックアップ |

## 文字から取り込む（無料・端末の中だけで動く）
予約メール・乗換案内の結果・メモを貼り付けると、形式がバラバラでも種類を見分けて予定にします。
宿（楽天トラベル・じゃらん・Booking など）／飛行機（便名・空港コード）／新幹線・電車（Yahoo!乗換案内・EX予約・Googleマップ）／高速バス／「10/12 9:30 伏見稲荷」のようなメモ。
スクショは iPhone の「写真」でテキスト認識 →「すべてをコピー」して貼り付けると、無料で高精度に読めます。
「Day 1」「8:15 – 10:15」「10:15 →」のような表形式の旅程表（移動・宿・食事・観光の分類、予備ルート・メモ欄つき）にも対応しています。
テスト: `node tests/parse.test.mjs`

## PDF の旅程表を取り込む（いちばん正確）
旅程表が PDF なら、スクショではなく PDF をそのまま選んでください。PDF の中の文字と位置を pdf.js（`vendor/pdfjs`）で取り出し、
表の行（時刻・内容・補足・分類）を組み立て直してから読むので、読み間違いがありません。文字の入っていない PDF（紙をスキャンしたもの）はページを画像にして読み取ります。

## スクショの読み取り
- **Gemini API キーあり**（設定 → AI → Gemini）: 画像を Gemini（既定: `gemini-flash-latest`）に送り、構造化された予定として受け取ります。Google AI Studio の無料枠で使えます。
- **Claude API キーあり**（設定 → AI → Claude）: 画像を Claude（既定: `claude-opus-5-5`）に送ります。高精度。
- **キーなし**: 端末の中で文字を読み取り（Tesseract.js）、簡単な規則で予定に分けます。読み取り後に手で直せます。

## アラームのしくみ（制約）
Web アプリは iPhone の時計アプリのように「アプリを閉じていても鳴る」ことはできません。
そのため寝る前に「おやすみモード」を開始し、アプリを開いたまま置く必要があります。
- **イヤホン節電モード**（既定）: 画面を暗くつけたまま待機し、鳴らす時だけ音を出す。イヤホンの電池をほぼ使わない。
- **確実モード**: 無音を流し続けて待機。画面を消しても鳴り、イヤホンが外れた瞬間に検出して無音にする。

## 旅仲間の共有（Firebase）
`firebase-config.js` に自分の Firebase の設定を貼ってください（手順はファイル内とアプリの設定画面にあります）。
Firebase コンソールの Firestore ルールに、アプリの「設定 → 旅仲間の共有 → 共有サーバー」に表示されるルールを追加してください。

## ファイル
- `index.html` / `app.css` … 画面
- `js/` … 機能ごとのプログラム（`alarm.js` がアラームの心臓部）
- `sw.js` … オフライン対応
- `make-icons.mjs` … アイコン（PNG）を作り直す道具（`node make-icons.mjs`）
